来体制内之前，我以为这是一条稳定、清晰的直线。

来了以后才发现，它更像一张被反复复印、盖章、传阅，最后还要确认有没有装订歪的流程图。

不是说不好，只是和我以前熟悉的运行环境差别太大。以前我面对计算机，输入指令，得到输出；现在面对现实世界，输入一句话，可能得到一句：

> 你先等一下，我再问问。

## 一、我的新手村，好像少加载了几个资源包

先说几个最直观的体验。

没有内网，没有食堂，我是个外地人。

这三件事单独看都不算大，叠在一起，就很容易让人产生一种“我是不是被随机分配到困难模式”的错觉。

别人中午讨论的是去哪个食堂、今天哪个窗口不排队；我讨论的是外卖满减怎么凑，以及附近哪家店能在二十分钟内把饭送到。

别人下班回的是家；我下班回的是宿舍。周末想回家，也不是买张票说走就走。距离不算天涯海角，但足以让“回家”变成一个需要提前规划的项目。

至于宿舍网络，怎么说呢。

它有一种很复古的美感。打开一个网页，先转圈；视频加载到一半，先缓冲；和家里人视频，画面卡成 PPT，声音倒是很稳定地告诉我：

> 网络连接已中断。

有时候我甚至怀疑，不是我在上网，是网络偶尔路过我这里。

## 二、线下办公：一种很新的复古体验

这里很多工作依然是线下完成的。

文件要打印，材料要签字，事情要当面问，联络很多时候靠打电话。手机在这一刻重新找回了它最原始、也最让人心跳加速的功能：

**来电。**

以前写代码，遇到问题可以查日志、看报错、复现步骤，实在不行还能搜索一下。现在遇到问题，先判断该问谁，再判断什么时候问，最后还要理解对方回答里的“应该可以”“差不多”“你看着办”分别是什么意思。

计算机至少会告诉我哪里错了。

现实工作常常只会告诉我：

> 这个事再研究研究。

我刚开始特别不适应。倒不是觉得线下一定不好，而是很多时间确实消耗在等待、跑动、确认和重复沟通上。以前我觉得并发难，后来发现“人一多，信息不同步”才是真正的分布式系统。

每个人手里都有一份自己的缓存，而且不一定愿意及时刷新。

## 三、基层的节奏：日历上有周末，工作不一定有

基层工作人员很辛苦，这一点我来了以后感受很深。

任务来得快，事情杂，很多时候没有完整的假期。刚进来那段时间，我甚至有一种错觉：不是我在安排工作，是工作在我身上进行压力测试。

一个任务还没收尾，下一个通知已经来了；刚准备喘口气，又被叫去处理另一件“很急”的事。所谓连轴转，大概就是你以为自己在一个线程里工作，实际上随时会被切走，处理完再切回来，并且忘了刚才做到哪。

最难受的不是忙。

忙其实还好，至少目标明确。

最难受的是那种一直待机、随时可能被叫走的状态。你很难真正休息，也很难彻底放松，因为心里总有一根线绷着，像后台常驻进程，关不掉。

## 四、以前我面对的是计算机，现在我面对的是人

以前我的工作逻辑很直接：

- 输入需求
- 写代码
- 运行测试
- 修 bug
- 输出结果

计算机不懂人情世故，也不会跟我寒暄。它不高兴了就报错，报错信息还可能非常具体。我们之间的关系简单、直接、冷漠，但高效。

体制内是另一套模式。

很多事情不能只看“技术上最快怎么做”，还要看流程、职责、历史原因、现实条件，以及这件事由谁来推动、出了问题由谁承担。

以前我觉得产品经理的需求已经够抽象了。现在回头看，产品经理至少会写需求文档。

现实工作里，每个人都可能临时变成产品经理，但不是每个人都写需求文档。

刚开始我会急，会在心里想：为什么不按最直接的方法来？

后来慢慢明白，不是所有人都在解决同一个问题。有人优先考虑效率，有人优先考虑风险，有人优先考虑责任边界，有人只是希望这件事今天别落到自己头上。

这不是一句“人情世故”就能概括的，它更像现实世界的约束条件。代码里我们可以假设理想环境，现实里每个约束都是真的。

## 五、崩溃是真的，学到东西也是真的

我不打算假装自己适应得很好。

我是一个心态比较容易崩的人。以前面对计算机，事情再难，至少路径相对明确：查资料、试方案、改代码、再试一次。体制内很多事情没有标准答案，也没有清晰的报错信息，只能边做边问、边错边学。

最开始那段时间，我经常一边干活，一边在心里默默重启自己。

但也不全是吐槽。

来了以后，确实学到了很多以前在外面接触不到的东西。比如一项政策怎么从文件落到基层，一件事为什么要经过那么多环节，不同部门之间如何协调，基层工作人员如何在资源有限的情况下把事情往前推。

以前我对很多社会运行方式的理解，都停留在新闻标题和想象里。现在至少知道，现实比标题复杂得多。

我也开始练习一些以前不太擅长的能力：

- 把模糊的问题问清楚
- 在信息不完整时先推进
- 理解别人的难处和立场
- 控制情绪，不把着急变成对抗
- 接受有些事情今天解决不了

这些能力不像写代码那样立刻能看到结果，但它们确实在改变我。

## 六、我在努力适应，但不想把自己磨没

适应一个新的环境，不代表要把原来的自己卸载掉。

我还是喜欢技术，喜欢把问题拆开、找到原因、解决之后长舒一口气的感觉。只是现在慢慢知道，技术不是解决问题的唯一方式，也不是所有问题都能靠效率解决。

我给自己定了一些很朴素的小目标：

- 能回家的时候就回家
- 网差就少刷视频，多看会儿书
- 心里憋闷就写下来，别全堆在心里
- 工作再忙，也保留一点自己的节奏
- 实在适应不了的部分，先观察，不急着否定自己

情绪不稳定不是罪。

在一个和自己过去经验完全不同的环境里重新学习，本来就会有不舒服的时候。能撑住、能调整、能继续往前走，已经很不容易了。

## 最后

如果以后有人问我，从天天面对计算机，到进入体制内工作，最大的感受是什么。

我大概会说：

以前的工作是：

```text
input -> output
```

现在的工作是：

```text
input
  -> 等通知
  -> 补充材料
  -> 请示
  -> 再等通知
  -> output（暂定）
```

吐槽归吐槽，日子还是要继续过，班还是要继续上，我也还在努力适应当中。

希望以后回头看这篇文章时，我已经能一边熟练处理这些事情，一边笑着说：

“当年那个连食堂都没有的地方，我现在居然也待明白了。”
